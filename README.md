# Superstore-Data-Analysis-Natural-Language-Q-A

## Project Overview

This project analyzes the Superstore dataset using Python and Pandas to identify important sales, profit, customer, product, geographical, and time-based business insights.

The project also includes a natural-language Q&A engine that allows users to ask business questions in simple English and receive data-driven answers.

## Objectives

- Clean and prepare the Superstore dataset.
- Perform exploratory data analysis (EDA).
- Identify important sales and profit patterns.
- Analyze customers, products, categories, states, and regions.
- Analyze business performance over time.
- Identify profitable and loss-making areas.
- Build a natural-language Q&A engine using Python and Pandas.
- Generate data-driven business insights.

## Natural-Language Q&A Engine

The project includes a rule-based natural-language Q&A engine developed using Python and Pandas.

Example questions:

- Which category has the highest sales?
- Which sub-category has the highest profit?
- Which customer has the highest profit?
- Which state has the highest profit?
- What are the total sales?
- What is the average order value?
- Which year has the highest sales?
- What is the average shipping time?

The engine processes the question and performs the relevant Pandas analysis to return a data-driven answer.

## Key Business Insights

- Technology generated the highest category-level sales.
- Technology generated the highest category-level profit.
- Phones was the highest-selling sub-category.
- Copiers generated the highest sub-category profit.
- Tables was a loss-making sub-category.
- The West region generated the highest sales and profit.
- Texas had high sales but recorded an overall loss.
- New York City generated the highest city-level sales and profit.
- 2018 recorded the highest annual sales and profit.
- High discounts were observed in a number of loss-making transactions.
